# Ferramentas Supera

Ferramentas de apoio para aulas online do Supera, feitas em uma única página HTML, sem instalação.

**Acesse:** https://griloteos.github.io/FerramentasSupera/

## O que tem

- **Tangram:** 7 peças para arrastar, girar (45°, 15° e 1°, com controle deslizante), espelhar, com mesa grande e zoom.
- **Ábaco Soroban:** 15 colunas, com a Unidade na 6ª coluna da direita, mostrando o dígito e o valor de cada coluna e o total.
- **Aprender regras:** explicações com animação passo a passo para troca de base 5, troca de base 10, multiplicação (1 e 2 multiplicadores) e divisão (1, 2 e 3 divisores, regra do 9 e tirar do quociente e colocar no dividendo).
- **Praticar:** exercícios sorteados para cada regra, com correção que explica o porquê do erro.

## Como atualizar

Substitua o `index.html`, faça commit e envie para a branch `main`. O GitHub Pages republica o site sozinho em cerca de um minuto.
